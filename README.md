# Apache KIE 10.3.0 Release Documentation & Evidence Repository

This repository contains the complete release procedure documentation, verification evidence, and release candidate artifacts for **Apache KIE 10.3.0 (Incubating)**.

---

## 1. Release Architecture & Overview

Starting in Apache KIE 10.3.x, the release procedure has been redesigned to be **local-first** and unified:
1. **Consolidated Java Reactor (`incubator-kie`)**: `drools`, `optaplanner`, `kogito-runtimes`, and `kogito-apps` are now unified in a single reactor under `incubator-kie`. Only a single build, R-commit, and staging workflow is required.
2. **KIE Tools Monorepo (`incubator-kie-tools`)**: Provides standardized local release scripts under `scripts/release/` supporting `--rc`, `--publish`, and `--skip-build` modes.
3. **Local-First Verification**: Developers can execute dry-runs and generate complete ASF-compliant release candidate bundles locally before triggering Jenkins jobs.

For the full detailed document, see [`release-procedure-10.3.md`](release-procedure-10.3.md).

## 2. Release Procedure

### A. Java Reactor Release Candidate (`incubator-kie`)
```bash
# 1. Checkout release branch
git checkout 10.3.x

# 2. Run local-first RC workflow (builds reactor, creates R commit and local tag)
./script/release/release-all.sh \
    --version 10.3.0 \
    --tag 10.3.0-rc1 \
    --skip-tests

# 3. (When deploying to Apache Nexus staging and pushing tag)
./script/release/release-all.sh \
    --version 10.3.0 \
    --tag 10.3.0-rc1 \
    --skip-tests \
    --deploy \
    --push-tag
```

### B. KIE Tools Release Candidate (`incubator-kie-tools`)
```bash
# 1. Bootstrap and set versions
pnpm bootstrap
pnpm update-version-to 10.3.0
pnpm update-kogito-version-to --maven 10.3.0
pnpm update-stream-name-to 10.3.0

# 2. Package all release artifacts
./scripts/release/release-all.sh 10.3.0 --rc

# 3. Artifacts will be generated in release-artifacts/
ls -lh release-artifacts/
```
